# STILLE serif faces

The mobile shell is fully serif:

- `CormorantGaramond-Regular.ttf` / `CormorantGaramond-SemiBold.ttf` — Latin
  display and labels (OFL-1.1).
- `STILLE-Song.ttf` — Noto Serif SC Regular 400, instanced from the Noto Serif
  SC variable font and renamed to a single Regular face (OFL-1.1).

The full OFL notice is in `OFL.txt`. The line mark and one-pixel rules remain
the graphic signature; typography is Songti/Cormorant throughout — all serif,
no sans-serif line face.
